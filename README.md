# LinkedIn Jobs: Company Blocker

There are many companies that post jobs on LinkedIn Jobs that you just don't want to see. This extension hides those cards for you.

This is a developer-mode extension, not published on the Chrome Web Store.

## Screenshot

![Screenshot of LinkedIn Jobs Company Blocker](screenshot.png)

## Install

1. Go to `chrome://extensions/`
2. Turn on **Developer mode**
3. Click **Load unpacked**
4. Pick this folder: `linkedin-jobs-company-blocker`

## Use

- **Block a company**: Click the 🚫 button next to the card’s X
- **Edit block list**: Click the extension icon, edit the newline list, click **Save**

Company matching is exact and case-sensitive.
